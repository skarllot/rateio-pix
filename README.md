# Rateio Pix

Aplicação estática para ratear assinaturas compartilhadas e gerar cobranças Pix individuais.

## Executar

Abra `index.html` no navegador ou publique a raiz do repositório no GitHub Pages. Não há backend nem dependências de produção.

## Testes

```sh
npm test
```

Os testes verificam a geração do payload Pix contra o exemplo BR Code fornecido, inclusive o CRC `AECF`.
